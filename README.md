# Бот учёта проходки и материалов

Telegram-бот для учёта проходки горных выработок, остатков материалов на складе и паспорта крепления. Работает через инлайн-кнопки, данные хранятся в SQLite.

## Возможности

- **Выбор забоя** — работа с несколькими выработками (например, «Северная», «Южная»).
- **Склад** — просмотр текущих остатков материалов и пополнение склада.
- **Проходка** — учёт пройденных метров по датам и сменам (1-я, 2-я, 3-я), замена/добавление/удаление данных, история за 7 и 30 дней, итог за месяц.
- **Паспорт крепления** — просмотр норм расхода материалов на 1 метр проходки и их редактирование (по паролю администратора).
- **Контроль доступа** — ботом могут пользоваться только авторизованные пользователи (белый список).
- **Управление пользователями** — администратор может добавлять и удалять пользователей, назначать роли (`operator` / `admin`).

## Архитектура

- `bot.py` — основной файл: обработчики команд, кнопок и текстового ввода, вся логика интерфейса.
- `bot_simple_bd_func.py` — работа с базой данных: инициализация, запросы, расчёт остатков и списания.
- `fastener_v3.db` — база данных SQLite (создаётся автоматически при первом запуске).

### Структура базы данных

- `materials` — справочник материалов (название, единица измерения).
- `excavations` — справочник выработок.
- `excavation_materials` — паспорт крепления: связывает выработку с материалами и хранит норму расхода на 1 метр.
- `supply` — приход материалов на конкретную выработку.
- `advance` — проходка (метры, дата, смена).
- `authorized_users` — белый список пользователей с ролями.

Остатки на складе считаются как `приход − расход`, где расход = `метры × норма расхода` из паспорта выработки.

## Установка и запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Задайте токен бота через переменную окружения:

   ```bash
   export BOT_TOKEN="ваш_токен_от_BotFather"
   ```

3. Запустите бота:

   ```bash
   python bot.py
   ```

## Требования

- Python 3.9+
- `python-telegram-bot` ~= 22.5

## Развёртывание на Railway

1. Запушьте код в GitHub-репозиторий (этот проект уже настроен под это).
2. В панели Railway: **New Project → Deploy from GitHub repo** → выберите `Bot_simple_fastener`.
3. Railway определит Python/Nixpacks автоматически (`railway.json` уже в репозитории).
4. В **Variables** добавьте `BOT_TOKEN` — токен от @BotFather.
5. Railway сам выполнит `pip install -r requirements.txt` и запустит `python bot.py`.

> ⚠️ **Важно про БД**: проект использует SQLite (файл `fastener_v3.db`). На Railway файловая система эфемерная — при каждом редеплое база пересоздаётся с нуля (таблицы создаются автоматически при старте, но данные теряются). Для постоянного хранения нужен [Volume](https://docs.railway.com/reference/volumes) или PostgreSQL.

## Настройка

- Первый администратор добавляется в `bot_simple_bd_func.py` (функция `user_system_database`, замените `user_id` на свой).
- Пароль для редактирования паспорта задаётся в `bot_app/config.py` (переменная `ADMIN_PASSWORD`).
